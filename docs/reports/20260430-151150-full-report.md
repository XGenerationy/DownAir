# Full Report

## Security issue addressed
Installer-generated `.env` contained high-value secrets but was previously left at default file mode in common root umask conditions.

## Remediation
- Added mandatory permission hardening:
  - `chmod 600 .env`
  - Confirmation output in installer logs.

## Impact
- Reduces attack path from unprivileged local users/processes reading deployment secrets.
- Helps protect JWT signing, token encryption/HMAC, and database credentials.
